## Các Điểm Hạn chế MVP Chưa Triển khai (Ghi nhận là Scope MVP chứ không phải Lỗi mới phát sinh)
- **GAP-01:** `WAITING_FOR_INFORMATION` chưa có Command, API endpoint và UI.
- **GAP-02:** Yêu cầu `DRAFT` chưa có endpoint chỉnh sửa nội dung (`PUT/PATCH`).
- **GAP-03:** `TaskChecklistItem` bị khóa sửa tại `BizFlowDbContext.SaveChangesAsync()` (chưa thể tick checklist trực tiếp).
- **GAP-04:** `EmailLinkAuthenticationService` chưa tích hợp SMTP gửi mail ra ngoài.
- **GAP-05:** `TaskWorkflowEngine.ConfirmResult` cho phép quản lý tự xác nhận task nếu nắm quyền `tasks.confirm`.
